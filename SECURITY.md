# Security Policy

## Scope

This repository contains small source-code utilities for Roblox Luau. It is an early-stage project and has not been independently security audited.

## Reporting a concern

Please do not publish secrets, exploit instructions, player data, or sensitive vulnerability details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile, and include:

- A concise description of the affected file and behavior.
- Steps to reproduce in a safe test environment.
- The potential impact.
- A suggested fix, if known.

Do not include real user data or credentials in reports.

## Security expectations

- Utility modules should not make unexpected network requests.
- Never commit API keys, access tokens, passwords, private game code, or player information.
- Review and test changes before using them in a live experience.
